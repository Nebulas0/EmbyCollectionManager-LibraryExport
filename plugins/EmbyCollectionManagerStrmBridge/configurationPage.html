Most Watched HomeScreen

Configure a dedicated, per-user HomeScreen section for each manager-owned Most Watched library. Select the same Movies/TV target library here and on the Collection Manager's Most Watched page.

Movies

Pick the same library selected on the Manager page, or leave Auto to follow its active output manifest.
Choose specific users or All users. New users are picked up the next time the bridge synchronizes.

TV Shows

Pick the same library selected on the Manager page, or leave Auto to follow its active output manifest.
Choose specific users or All users. New users are picked up the next time the bridge synchronizes.
Choose the same Movies/TV output library as on the Manager's `/most-watched` page, or leave Auto-detect to follow the active library recorded in the Manager's manifest.
Poster and Thumb/Landscape files are generated separately on the Manager's Most Watched page. Enable the matching image version there as well. These settings affect only this plugin's dedicated Top Played sections. The bridge excludes the selected output library from other HomeScreen sections for those users, so its items appear in the ranked row; other libraries and their sort settings are left unchanged. STRM exports can always be isolated. Symlink items are updated only when Emby indexes them as distinct items; the bridge will not change a source item if Emby resolves a symlink to that item. The bridge adds its own row; if a client has a separate pinned shortcut to the library, hide that shortcut manually to avoid seeing the same titles twice.
