How the ranked libraries work

Playback events are matched by Emby item ID and restricted to the selected source libraries; episode plays are grouped under their Series. Ranked entries use symlinks to the original media files plus NFO sidecars and numbered posters generated from existing Emby/local artwork. Source artwork is read only; no video data is copied. Rank-prefixed folders and NFO sort titles keep the order. Emby should sort by Name/Sort Name ascending; clients using another sort order may need that changed. Regular collection exports continue to use their existing directory symlinks.
