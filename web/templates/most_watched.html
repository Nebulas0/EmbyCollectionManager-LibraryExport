How the ranked libraries work

Playback events are matched by Emby item ID and restricted to the selected source libraries; episode plays are grouped under their Series. Choose real media symlinks or STRM path pointers. NFOs and selected numbered poster/thumb images are generated in the ranked output folders; source artwork stays read only and no video data is copied. Rank-prefixed folders, NFO sort titles, and indexed STRM item Sort Names keep the order. Emby should sort by Sort Name ascending; clients using another sort order may need that changed. Regular collection exports continue to use their existing directory symlinks.
